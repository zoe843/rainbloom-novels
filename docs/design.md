# 雨落花庭·书阁

2026-10-17。依据：用户确认站外 AI 创作、Git 提交内容、github.io 地址、沿用个人站风格，并要求开始制作。

## 目标与范围

为自己提供适合电脑和手机的静态小说阅读站。GitHub Pages 发布，后续从 rainbloom.xin 导航接入。本次不修改个人网站。无账户、无访客内容写入、无在线模型调用。公开的两篇示例短篇清楚标记为 AI 示例。

## 视觉与结构

沿用个人站 #0c1824 夜蓝、#e3e7e8 月白、#a9c5d3 雾蓝、#c8a7b7 花瓣粉、#132230 深色面板。宋体用于站名、书名、章节与正文，无衬线用于控件。首页以真实书封和继续阅读为中心，避免大幅装饰压过内容。正文提供夜色/纸色两种主题，18–28px 字号、1.6–2.4 行距、560–900px 阅读宽度与两种字体。

书架 → 小说详情与目录 → 阅读页。阅读记录与书签独立页面。桌面有侧目录，手机用原生对话框。所有内部路由用 hash，支持 GitHub 项目子路径和刷新。页尾可返回个人网站。

## 内容与数据

content/<book-id>/book.json 定义稳定的书籍、章节 ID 与排序；chapter.md 为正文，第一行一级标题是章节名。构建时校验文件、重复 ID、必填字段、相对路径与空文本，输出 dist/data/catalog.json 与逐章 JSON。浏览器将正文作为文本节点渲染，允许段落、小标题、引用、分隔线，不执行 HTML。

localStorage 保存进度、设置和书签，跨设备不同步；页面明确说明。使用章节稳定 ID 与段落位置恢复，修改排版时保留段落锚点。存储失败仍允许阅读并提示无法保存。未知路由显示可返回书架的错误页，网络失败允许重试。

## 验收

构建校验；320/390/768/1440 宽度无横溢；章节跳转、目录、返回、深链刷新、字体设置持久化、进度恢复、增删书签、搜索、空结果、存储损坏与读取失败可恢复；无控制台错误。GitHub Actions 构建并部署，确认正式网址和线上交互。
